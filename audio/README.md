# 旁白音频放这里

演示页 `视频演示.html` 会自动扫描本目录。**放进来就生效，不用改任何代码。**

## 两种放法（任选其一）

### 放法一：整段旁白（推荐，最省事）

把录好的完整旁白命名为：

```
audio/narration.mp3
```

页面会把它挂到整条时间轴上，播到第几秒就跳到音频第几秒，暂停、重播、拖镜头都会跟着走。

### 放法二：分镜音频（音画对得更准）

按镜头顺序拆成 7 段：

```
audio/1.mp3   镜头1  开场提问        0s 开始
audio/2.mp3   镜头2  三个痛点        6s 开始
audio/3.mp3   镜头3  产品亮相       13s 开始
audio/4.mp3   镜头4  实时打分演示   20s 开始
audio/5.mp3   镜头5  交互查询页     31s 开始
audio/6.mp3   镜头6  功能全景       42s 开始
audio/7.mp3   镜头7  收尾 + GitHub  53s 开始
```

切到某个镜头时，对应的那段音频就会播放。

## 还能拖文件直接试

不想先放文件也行——打开页面后：

- 点左上角的橙色提示条，或按 **A** 键
- 选 1 个文件 → 当成整段旁白
- 选 7 个文件（按顺序多选）→ 当成分镜音频

选完立刻生效，适合先试听音色对不对，再决定要不要固化到 `audio/` 目录。

## 支持格式

`.mp3`（最稳）、`.m4a`、`.wav`。**不接受 mp4**——mp4 是视频容器，浏览器拿不到音轨时间轴，请先抽出音频：

```
ffmpeg -i 源文件.mp4 -vn -acodec libmp3lame -q:a 2 audio/narration.mp3
```

如果是剪映导出的作品，直接选「音频导出 → MP3」即可。

## 时长建议

整片 60 秒，7 段旁白按镜头时长对齐：

| 镜头 | 可用时长 | 旁白字数参考 |
|------|---------|-------------|
| 1 | 6s | 15–20 字 |
| 2 | 7s | 18–22 字 |
| 3 | 7s | 18–22 字 |
| 4 | 11s | 28–35 字 |
| 5 | 11s | 28–35 字 |
| 6 | 11s | 28–35 字 |
| 7 | 7s | 18–22 字 |

旁白文本见 `../视频配音稿.md`。音频比镜头长也没关系——下一段会自然覆盖，只是收尾略赶；短一点更从容。
