# 旁白音频放这里

演示页 `视频演示.html` 和渲染脚本会自动扫描本目录。**放进来就生效，不用改代码。**

## 当前状态

| 文件 | 说明 |
|------|------|
| `narration.mp3` | 整段旁白，44.35 秒（曼波音色） |
| `1.mp3` ~ `7.mp3` | 由 narration.mp3 按句子边界自动切分的分镜音频 |

**页面优先使用分镜音频**（`1.mp3`~`7.mp3`），因为每段严格对应一个镜头，音画天然同步。

---

## ⚠️ 血泪教训：整段音频的长度必须与视频时间轴一致

第一版出过这个问题：音频是 44.35 秒，视频时间轴却按 60 秒铺开。
结果音频念完第 7 句时，画面才走到第 5 个镜头——**后面 15 秒全是无声，字幕还和声音错位**。

原因：整段音频是靠"按时间轴 seek"定位的，如果两者长度不一致，误差会一路累积。

**所以有两条铁律：**

1. **录整段旁白时，总时长必须等于视频时长**，或者
2. **用分镜音频**（每句话单独一个文件），这样每段只需在对应镜头开始时播放，不累积误差 ✅

---

## 两种放法

### 放法一：分镜音频（推荐，最精确）

按镜头顺序拆成 7 段，命名 `1.mp3` ~ `7.mp3`：

| 文件 | 镜头 | 起始时间 | 时长 | 旁白字数 |
|------|------|---------|------|---------|
| `1.mp3` | 开场提问 | 0.00s | 4.55s | 25 字 |
| `2.mp3` | 三个痛点 | 4.55s | 5.53s | 29 字 |
| `3.mp3` | 产品亮相 | 10.08s | 3.69s | 19 字 |
| `4.mp3` | 评分榜单 | 13.77s | 7.64s | 40 字 |
| `5.mp3` | 交互查询页 | 21.41s | 7.68s | 39 字 |
| `6.mp3` | 功能全景 | 29.09s | 7.30s | 40 字 |
| `7.mp3` | 收尾 | 36.39s | 7.91s | 47 字 |

**7 段必须齐全**，缺任何一段就整组不生效，自动退回整段模式。

### 放法二：整段旁白

```
audio/narration.mp3
```

整段音频总长**必须等于视频总长（44.30 秒）**，否则会不同步。

自动切分命令（已执行过，供重新生成时参考）：

```bash
FF="你的ffmpeg路径"
for spec in "1 0 4.5515" "2 4.5515 10.0757" "3 10.0757 13.7681" "4 13.7681 21.4069" \
            "5 21.4069 29.0906" "6 29.0906 36.3914" "7 36.3914 44.35"; do
  set -- $spec
  "$FF" -y -i narration.mp3 -ss $2 -to $3 -c:a libmp3lame -q:a 2 "$1.mp3"
done
```

切分点取自静音检测（`silencedetect=noise=-35dB:d=0.25`）识别的句子边界中点，
换新录音时需要重新跑静音检测来定位边界。

## 还能拖文件直接试

打开页面后：

- 点左上角的橙色提示条，或按 **A** 键
- 选 1 个文件 → 当整段旁白
- 选 7 个文件（按顺序多选）→ 当分镜音频

选完立刻生效，先试听音色对不对，再决定要不要固化到 `audio/` 目录。

## 支持格式

`.mp3`（最稳）、`.m4a`、`.wav`。**不接受 mp4**——mp4 是视频容器，浏览器拿不到音轨时间轴，请先抽出音频：

```
ffmpeg -i 源文件.mp4 -vn -acodec libmp3lame -q:a 2 audio/narration.mp3
```

剪映导出的作品，直接选「音频导出 → MP3」即可。
