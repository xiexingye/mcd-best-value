# 性价比评分模型

用于把"这个套餐值不值"从主观感觉变成可比较的分数，确保不同方案之间有**区分度**。

## 一、评分公式

```
性价比分(0-10) = 饱腹价值 × 0.40
               + 优惠力度 × 0.30
               + 营养均衡 × 0.20
               + 场景契合 × 0.10
```

四项各自折算到 0–10 分，加权求和后保留一位小数。

### 1. 饱腹价值（权重 0.40）

衡量"花这个钱能吃到多少实打实的食物"，核心是**每元食物的分量**。

| 判断维度 | 高分特征 |
|----------|----------|
| 主食量 | 含 1 个及以上完整汉堡/主食 |
| 配餐量 | 含薯条/鸡块等小食，而非只有饮料充数 |
| 单价 | 实付价 ÷ 主要食物件数 越低越高 |
| 饮品位 | 不与食物同价的"纯溢价"饮料（如单独大杯饮料占价过高）扣分 |

参考打分：
- 9–10：主食+小食+饮料齐全，实付价低于同构成单点总和 20% 以上
- 7–8：主食+（小食或饮料），单价合理
- 5–6：仅主食，或构成单薄
- <5：以饮料/甜品为主，饱腹感弱

### 2. 优惠力度（权重 0.30）

```
优惠率 = (原价 - 实付价) / 原价
```

| 优惠率 | 得分 |
|--------|------|
| ≥ 30% | 9–10 |
| 20%–30% | 7–8.9 |
| 10%–20% | 5–6.9 |
| < 10% | 3–4.9 |
| 无优惠 | 0–2.9 |

加分项：使用了**当日限时券**或**可叠加活动**，额外 +0.5（上限 10）。
减分项：需要凑单才能用券，凑单商品用户并不需要。

### 3. 营养均衡（权重 0.20）

结合 `list-nutrition-foods` 的热量、蛋白质、脂肪、钠数据。

| 场景 | 高分特征 |
|------|----------|
| 常规 | 蛋白质 ≥ 20g，热量 500–800 kcal，钠不过高 |
| 减脂 | 热量 ≤ 550 kcal 且蛋白质 ≥ 20g，或可用"去酱/无糖饮"调整 |
| 增肌/管饱 | 蛋白质 ≥ 30g，热量 700–900 kcal |

参考打分：
- 9–10：营养结构均衡，符合目标场景
- 6–8：基本合格，有 1 项偏高/偏低
- 3–5：高油高钠，或纯碳水+糖
- <3：显著不符合用户目标（如减脂却点了大杯可乐+麦旋风）

### 4. 场景契合（权重 0.10）

用户当前场景与方案特征的匹配度。

- 一人食：单人份、易携带（到店自取友好）
- 双人/多人：有分享装、第二份半价等
- 赶时间：即取即走、无需等待重制
- 下午茶：小食+饮品组合，客单价低
- 减脂：低卡组合

契合 → 8–10；一般不冲突 → 5–7.9；明显不匹配 → 0–4.9

## 二、推荐程度（星级）换算

性价比分 → 推荐星级与话术：

| 性价比分 | 星级 | 话术标签 |
|----------|------|----------|
| ≥ 9.0 | ★★★★★ | **闭眼冲** — 今日最值，性价比天花板 |
| 8.0–8.9 | ★★★★☆ | **强推** — 非常划算，值得优先考虑 |
| 7.0–7.9 | ★★★☆☆ | **推荐** — 性价比较好，适合特定需求 |
| 6.0–6.9 | ★★☆☆☆ | **尚可** — 有更好的替代，除非正好想要 |
| < 6.0 | ★☆☆☆☆ | **不推荐** — 性价比一般，建议换方案 |

> 榜单内避免所有方案同为五星：头名给 ★★★★★，第二梯队 ★★★★☆ 或 ★★★☆☆，形成梯度。

## 三、适合人群标签库

推荐时必须从下列标签中选择（可多选），并**结合具体方案补充细节**：

- **学生党 / 预算敏感型**：总价低、饱腹强
- **上班族 / 赶时间**：出餐快、单手可食、到店自取方便
- **减脂人群**：低卡高蛋白，可调整（去酱、无糖饮）
- **健身增肌**：高蛋白、热量充足
- **大胃口 / 管饱型**：主食量足，分量实在
- **两人分享 / 情侣**：有分享装或第二份优惠
- **下午茶 / 加餐**：低客单价小食+饮品
- **家庭 / 带娃**：有儿童友好餐品、口味温和
- **尝鲜 / 玩梗**：新品、联名、限定款

## 四、评分脚本用法

`scripts/value_score.py` 接收候选方案 JSON，输出按性价比分排序的榜单。

输入格式（数组，每项一个候选方案）：

```json
[
  {
    "name": "1+1随心配",
    "components": ["双层吉士堡", "中薯"],
    "original_price": 25.5,
    "final_price": 13.9,
    "calories": 620,
    "protein_g": 24,
    "scene": "学生党",
    "is_limited_coupon": true
  }
]
```

- `final_price` 必须是 `calculate-price` 返回的**实付价（元）**
- 营养数据来自 `list-nutrition-foods`
- 运行：`python scripts/value_score.py candidates.json`

输出：每个方案的 four 项子分、加权总分、星级、话术标签，按总分降序。
