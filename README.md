# 麦门省钱与性价比推荐助手（mcd-best-value）

> 麦当劳程序员节创意开发大赛参赛作品

一个基于**麦当劳 MCP** 的 WorkBuddy Skill：每天实时拉取门店菜单与优惠券，计算每个套餐的**性价比评分**，评选出当天最值的方案，标注**适合人群**与**推荐程度**，并生成**交互式网页**供用户按预算、场景自由筛选，还支持一键下单。

## 目标用户

- **学生党 / 预算敏感型**：想吃好又不想多花钱，需要"最值组合"直接拍板
- **上班族**：午休时间有限，想知道今天点什么划算、有没有券能用
- **减脂 / 健身人群**：需要在热量、蛋白质约束下找到合适搭配
- **多人聚餐场景**：两人、家庭分享，需要人均最优解
- **所有麦当劳用户**：不想在几十个套餐里反复比较

## 核心功能

| 功能 | 说明 |
|------|------|
| 🕐 **实时查询** | 每次调用都当次拉取麦当劳接口，价格、优惠券、在售状态都是当前时刻的真实数据 |
| 📊 **性价比评分** | 四维加权模型：饱腹价值 40% + 优惠力度 30% + 营养均衡 20% + 场景契合 10% |
| 🏆 **当日性价比榜单** | 输出 3–8 个方案，覆盖不同价位与场景，按推荐程度排序 |
| 🥇 **适合人群标注** | 每个方案标注"学生党 / 上班族 / 减脂 / 双人 / 下午茶"等人群标签 |
| ⭐ **推荐程度分级** | 5 星制（闭眼冲 / 强推 / 推荐 / 尚可 / 不推荐），拉开梯度不千篇一律 |
| 🍔 **套餐组成明细** | 逐项列出主食/小食/饮料/甜品的名称与数量，标注可替换项 |
| 🖥️ **交互式查询页** | 生成自包含 HTML：预算滑块筛选 + 场景标签 + 4 种排序 + 详情展开 |
| ⏰ **定时推送** | 每天 12:00 自动生成并推送当日榜单 |
| 🛒 **一键下单** | 用户确认后可直接创建订单 |

## 安装方法

本 Skill 为 WorkBuddy 技能包，安装步骤如下：

1. **确认环境**：已安装 WorkBuddy，并已连接「麦当劳 MCP」连接器（mcd-mcp）。
2. **安装技能**：将 `skill/` 目录整体复制到用户技能目录：
   ```
   ~/.workbuddy/skills/mcd-best-value/
   ```
   （Windows 下为 `C:\Users\<用户名>\.workbuddy\skills\mcd-best-value\`）
3. **验证目录结构**：
   ```
   mcd-best-value/
   ├── SKILL.md
   ├── references/
   │   ├── api-reference.md
   │   └── scoring-model.md
   └── scripts/
       ├── value_score.py
       └── render_board.py
   ```
4. （可选）**安装定时任务**：在 WorkBuddy 中创建一个每天 12:00 的自动化，提示词调用本技能生成榜单。

## 使用示例

安装后，直接对 WorkBuddy 说：

**示例 1｜日常比价**
> 用户：今天中午吃什么划算？
> 助手：实时拉取附近门店菜单与券 → 计算性价比 → 生成交互式榜单网页

**示例 2｜预算约束**
> 用户：30 块以内推荐一个套餐
> 助手：筛选 ≤¥30 的方案，输出该价位内最值的前几名

**示例 3｜减脂场景**
> 用户：减脂想点麦当劳，怎么点？
> 助手：结合营养数据，推荐低卡高蛋白组合，标注热量与蛋白质

**示例 4｜多人场景**
> 用户：两个人吃，怎么点最划算？
> 助手：计算分享装的人均成本，给出双人最优解

**示例 5｜找优惠**
> 用户：麦门今天有什么券？
> 助手：拉取门店可用券 + 可领取券，说明哪些方案能用券省多少

## 输出示例

生成的交互式查询页包含：

- **预算滑块**：拖动实时过滤该预算内的方案
- **场景标签**：点选 学生党/上班族/减脂/双人/下午茶，榜单实时重排
- **排序切换**：性价比↓ / 价格↑ / 省最多 / 热量↓
- **详情展开**：点击查看完整组成、热量蛋白质、用券明细、适合人群

每个方案卡片展示：

```
🥇 双层吉士汉堡 + 中薯条
├ 主食：双层吉士汉堡 ×1
├ 小食：中薯条 ×1
├ 原价 ¥30.00 → 实付 ¥19.00（省 ¥11.00）
├ 性价比分：8.7/10
├ 适合人群：学生党 / 大胃口 / 管饱（718kcal，蛋白 31g）
└ 推荐程度：★★★★☆ 强推
```

> 分值由 `skill/scripts/value_score.py` 按评分模型实算得出（示例为参考数据）。
